# 📝 To-Do Task Manager App

A responsive and modern web application that helps users manage their daily tasks efficiently.  
Each user can **register**, **log in**, and manage their **own tasks** privately — all data is stored locally per account.

---

## 🚀 Features

- 🔐 **User Authentication** – Register and log in system.
- 🗂️ **Personal Task Storage** – Each user has their own task list saved in LocalStorage.
- ⚙️ **CRUD Operations** – Create, Read, Update, and Delete tasks.
- 🎨 **Dark / Light Mode** – Toggle between light and dark themes.
- 🏷️ **Task Categorization** – Organize tasks by status: `Next Up`, `In Progress`, `Done`.
- ✅ **Form Validation** – Real-time input validation for better UX.
- 🔔 **Toast Notifications** – Visual feedback using Toastify.js.
- 💻 **Responsive Design** – Works seamlessly across devices using Bootstrap.

---

## 🧩 Tech Stack

| Technology | Description |
|-------------|-------------|
| **HTML5** | Structure and layout |
| **CSS3** | Styling and animations |
| **Bootstrap 5** | Responsive UI framework |
| **JavaScript (ES6)** | Core logic and CRUD operations |
| **LocalStorage API** | Persistent task saving per user |
| **Toastify.js** | Toast notifications for user feedback |


---

## ⚙️ How It Works

1. **Register** a new user with email & password.  
2. **Login** to access your personalized task board.  
3. **Add new tasks** and assign:
   - Title  
   - Description  
   - Category  
   - Status (`Next Up`, `In Progress`, `Done`)  
4. **Edit or delete** tasks easily.  
5. **Switch** between light and dark modes anytime.  
6. **All tasks are saved** locally per user (using `localStorage`).
