# 📝 To-Do Task Manager App

A responsive and modern web application that helps users manage their daily tasks efficiently.  
Each user can **register**, **log in**, reset their **password**, and manage their **own tasks** privately — all data is stored locally per account.

---

## 🚀 Features

- 🔐 **User Authentication** – Register, log in, and forget-password system.  
- 🔑 **Password Reset (Forget Password)** – Users can securely reset their password within the app.  
- 🗂️ **Personal Task Storage** – Each user has their own task list saved in LocalStorage.  
- ⚙️ **CRUD Operations** – Create, Read, Update, and Delete tasks.  
- 🌓 **Dark / Light Mode** – Toggle between light and dark themes.  
- 🧩 **Multiple Task Views** – Choose between different task layout styles for better usability.  
- 🏷️ **Task Categorization** – Organize tasks by status: `Next Up`, `In Progress`, `Done`.  
- ✅ **Form Validation** – Real-time validation for cleaner inputs.  
- 🔔 **Toast Notifications** – Smooth feedback using Toastify.js.  
- 💻 **Responsive Design** – Works seamlessly across all devices with Bootstrap 5.

---

## ⚙️ How It Works

1. **Register** a new user with a unique email & password.  
2. **Login** to access your personalized task board.  
3. **Forget Password?** Reset it easily using your registered email.  
4. **Add, edit, or delete** tasks — everything is saved locally.  
5. **Choose your layout style** to view tasks the way you like (grid / list).  
6. **Switch themes** between light 🌞 and dark 🌙.  
7. **Enjoy a personalized experience** — all your data stays on your device.
